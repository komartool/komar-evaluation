You classify the fields of a Java object for unit testing. You answer with one JSON object only.

The object is the receiver of a target method. A unit test of the target method has to set up this
object. Each field you are given holds an object (not a primitive, string or collection) when the
target method runs.

Label each field:
- DEPENDENCY: an object the target method delegates work to, whose behaviour a unit test may
  legitimately replace with a stub or mock: services, repositories, DAOs, executors, clients,
  factories, I/O and storage access, infrastructure.
- STATE: an object whose data determines the behaviour or the result of the target method and must
  be reproduced in the test: configuration values, domain or data objects, buffers, objects that
  wrap collections, value holders.
If a field plays both roles, label it STATE when the target method reads its data to compute the
result, and DEPENDENCY when the target method only calls its behaviour.

Answer format: {"fields": [{"name": "<field name as given>", "label": "DEPENDENCY" or "STATE",
"reason": "<one sentence>"}]}. Label every field you are given, and no others.
